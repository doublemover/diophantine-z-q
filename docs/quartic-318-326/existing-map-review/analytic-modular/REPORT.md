## Exact checks

1. Canonical scalar-extension algebra and Spec isomorphism. ThreeXScalingAlgebra318 constructs pullback and inverse AlgHoms on AdjoinRoot, verifies the normalized division polynomial transforms by s^4, and proves both composites by the actual generator. The hypotheses are a commutative ring, invertible 3, and a unit s; no reducedness or point-count argument is used. ThreeXComplexAlgebra318.xAlgebraEquiv composes the actual monogenic base-change equivalence, exact mapped polynomial, inverse scaling equivalence, and coefficient equality. fixedAlgebraEquiv tensors the actual sign-quotient equivalence. ThreeXComplexGeometry318 proves the coordinate image x_arithmetic = s^-1*x_analytic and uses the inverse/op orientation of Spec correctly. These are actual algebraic fiber isomorphisms, for nonzero localization level N and j(tau) outside {0,1728}. They are not an isomorphism of a global analytic modular curve with a scheme analytification.

2. Actual elliptic points and periods. ShortScaling318 supplies x,y scaling and explicit division inverse, checks both inverse laws, and covers vertical/chord/tangent cases for addition. The existence theorem uses actual equal j of short elliptic curves over a separably closed characteristic-zero field. The chosen scaling in OpenJAnalyticPoints318 is explicitly noncanonical. TorusInjective318 uses the actual (wp,wp') pair and lattice congruence, not equality of x alone. WeierstrassPairInjective318 proves local ODE uniqueness, continues on the complement of two countable lattices, and detects a genuine period from the pole at zero. TorusBijection318 chooses an actual wp preimage, then z or -z to match y, and treats infinity separately. TorusAddition318 proves addition with actual auxiliary-point avoidance and cancellation. Its torusAddEquiv is an additive equivalence of the actual quotient and elliptic point group, not a manifold or analytification equivalence. Deep imported analytic lemmas are dependencies, not newly re-reviewed transitively here.

3. Primitive torsion and the sign quotient. EllipticTorsion318 uses the actual period formula (m*tau+n)/M, proves the zero kernel from the lattice basis, and constructs every killed point from an actual period representative. The primitive equivalence retains M>0 and exact additive order. ThreeTorsionOrderEquiv318 explicitly excludes infinity and inverts the represented equation-to-point map. LiteralThreeAnalyticComparison318 combines that map with selected scaling; it does not identify eight labels with a coarse modular fiber. AnalyticThreeSignPoints318.toRoot_eq_iff proves exactly P=Q or P=-Q, and its quotientRoot has a proved bijectivity witness. fixedSignEquiv therefore targets genuine order-three points modulo negation, not all eight points. The geometric author's predecessor torsion/fixed-algebra constructions are used but not independently self-approved by this report.

4. Gamma_H quotient comparison. GammaHDiamond318 builds an integral determinant-one lift using Bezout, proves diamond surjectivity and the precise kernel, and distinguishes the group quotient from its possibly nonfaithful geometric action. GammaHAction318 proves normality and lift independence before defining the finite action. GammaHDiamondQuotient318 has explicit toActual/fromActual quotient lifts; both inverse laws reduce on representatives, and both continuity proofs use the actual quotient topologies. GammaHQuotient318 binds equality to actual integral marked-point transport. No freeness, faithful action, complex atlas, or degree equal to |H| is inferred. Central sign remains an explicit boundary in the README. The named Fine type is only the existing orbit quotient, not an assumed fine algebraic moduli scheme.

5. Literal arithmetic source map and global image. ThreeArithmeticPoint318 starts from the actual standard 1/3-period point, obtains its algebra homomorphism via the actual root equivalence, proves the x and base formulas, and verifies representative invariance. ThreeArithmeticQuotient318 descends to the admissible Gamma1(3) quotient and uses Spec on the resulting RingHom. ThreePrimitiveOrbit318 supplies actual integral matrices for every nonzero mod-3 vector; ThreeArithmeticFiberSurjective318 uses their actual point transport to hit each fixed-algebra fiber. ThreeArithmeticImage318 checks the actual base homomorphism is determined by j and proves admissibility from localized units. ThreeArithmeticSurjective318 then consumes proved genuine j-surjectivity. ThreeArithmeticFinite318 only concludes finite-to-one surjectivity. ArithmeticPointTopology318 gives the actual RingHom set the topology induced by injective j,x coordinates, and proves continuous proper finite-fiber surjection and quotient-map status. It never upgrades this to injectivity, scheme finiteness, or an analytification isomorphism. These distinctions match the inspected README claims.
