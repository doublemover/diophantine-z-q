# An exact nonzero Heegner jet on a test curve

This calculation exercises the entire moving-prime test on a tractable, separate curve: the original marked class points, the signed modular trace, the rational twist point, and the invariant local differential. The local calculation gives 4 modulo 5, independently of the directly computed rational point. The ordinate sign follows the common convention in the note.

This validates the method on a genuine modular example. It does not compute a value for the quartic's selected twists or supply the missing rational witnesses.
