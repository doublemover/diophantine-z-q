# The first ordinary dyadic Heegner bit is zero on the exact original selector

Read [the correction proof](proof/EXACT-ORDINARY-GENUS-DEPTH-AND-NORMALIZED-HEEGNER-BIT.md)
and [independent signed check](independent-review/INDEPENDENT-ORDINARY-GENUS-DEPTH-REVIEW.md).
Run 'sh verify.sh' to verify the exact bound files.

The earlier conditional sufficiency was correct: a nonzero first
binary phase would have certified a nontorsion trace. The new
genus-character comparison proves that particular phase is zero on
every original arm in the stipulated split-at-2 selector, including
the neutral-helper extensions. Thus the fixed first-bit Frobenius
hit set on the named selector is empty, not merely unevaluated.

Counting all usable primes that are 1 modulo 24 gives a stronger
exact logarithmic depth. A more deeply normalized bit uses the
same edge statistic on a joint genus slice. No value of that new
bit, actual unweighted Heegner trace, rank, or marked point is
computed here. This is not a claim that the trace itself vanishes.
