# Signed finite detector and a sparse fibre test

The mod-61 rank detector reduces to a signed class-orbit statistic. Its signs cannot be discarded, even after imposing the exact involutions. An independently replayed zero on the same lower modular level provides a control. An individual detector value can be recovered from Frobenius on a single fibre if the required cyclic cover is supplied; it is not furnished by a congruence-level cover or by a modular unit supported at cusps.

This does not calculate a nonzero value in the selected family, construct the missing noncuspidal cover, or give a lower bound on the cost of calculating the actual trace.
