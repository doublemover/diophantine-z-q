## D. An explicit low-level reduction recipe for the actual π, not a high-level solver

We can choose the based π for this new datum without computing a genus-huge equation at level 5,007,792. Start at the actual X₀(48) model y²=x⁸+14x⁴+1 of [Bruin–Najman](https://arxiv.org/abs/1406.0655) and [Colò Appendix A (moduli degeneracy formulas)](https://www.leonardocolo.com/documents/thesis/PhD_Thesis.pdf). Define u=(x−1/x)/2, v=y/(4x²) on the dense chart, so v²=u⁴+u²+1. Then A=(v+1)/u², B=(A²−1)u give precisely (2A+1,2B) on the original E_{−1}: y²=x(x+1)(x−3). This nonconstant map extends across exceptional points by smooth properness, is the degree-two quotient (compatible with [Brunault §6.3](https://perso.ens-lyon.fr/francois.brunault/recherche/reg_siegel.pdf)), and becomes based after subtracting its true modular ∞ value. That subtraction cancels in the nontrivial quadratic twist sum. Identifying the canonical modular points with this curve model still uses its genuine moduli coordinate maps, not arbitrary x,y satisfying the equation.

Write χ=χ_{−d} and pick s=∑_{a mod d}χ(a)ζ_d^a, so s²=−d. Analytically define the one actual map

    π_d(z)=i_s(∑_{a mod d} χ(a) φ₀(z+a/d)),
    i_s(X,Y)=((−d)X,s³Y),

where φ₀ is the based map above. For γ=(α β; c δ)∈Γ₀(48d²) the fractional translations satisfy T_a γ T_{−b}∈Γ₀(48) with b≡aδ/α≡aδ² mod d (c contributes integral entries). Hence the terms permute with the same weights, and the sum descends to the complex curve. The sum vanishes at ∞. In its local q-series the translates multiply coefficients by ζ_d^{a m}; Galois permutes these translates by the same unit and acts on their signed sum by χ. The twist i_s has precisely the sign dependence on s, so the q-expansion principle descends the actual rational map to E_d.
