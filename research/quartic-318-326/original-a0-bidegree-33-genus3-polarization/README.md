# No eight-branch degree-(3,3) rational parametrization at the fixed original scalar

A shared eight-point branch divisor for the two degree-three parameter maps would give a genus-three double cover. Its two degree-three elliptic quotients would force a rational cyclic order-three subgroup; the exact normalized division polynomial rules this out modulo 5.

This applies to the archived original input-0 scalar, not to another scalar or a synthetic specialization. It does not exclude the twelve-branch case or any individual rational PointPair.

The only branch calculation used is that adjoining the square root of the quartic evaluated at the first parameter gives the common double cover. Eight simple branch places give genus three by Riemann–Hurwitz. Each parameter map has degree three, so the source double cover's maps to the two elliptic forms have degree three by the field-degree tower. No geometric candidate enumeration is part of this package.

Run sh verify.sh with Python 3, cmp and sha256sum to verify exact files and the normalized division-polynomial residue calculation.
