`actual-two-class-local-contact-cover` packet. It proves a three-dimensional
pair-supported subspace of the 2-Selmer group, independent of the two rational
torsion classes. It reduces the two pairing tests for the marked class against

evaluated. Passing both would only show orthogonality against this subspace;
no rational point, rank, or nontrivial Tate–Shafarevich class is asserted.
