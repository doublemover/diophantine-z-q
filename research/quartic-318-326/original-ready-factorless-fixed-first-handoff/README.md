# An exact first half on each literal Ready pole

For each already-Ready rational pole, the fixed formula supplies a rational first marked point without factoring squareclasses, choosing a final prime, or invoking a rank theorem. The companion is an explicit everywhere locally soluble genus-one quartic. An affine point on that actual quartic gives exactly the needed second half of the original PointPair.

On the common-index four-Ready source this gives four rational first halves, but **still requires four global companion points**. The archived input-0 scalar/short-anchor source is an already-defined separate scalar specialization: one affine point on its stated quartic would supply that scalar PointPair only. Neither this result nor the replay proves a global companion point or a fixed selected twist's rank.
