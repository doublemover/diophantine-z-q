# The fixed original scalar has no generic raw companion section

For the archived original input-0 scalar, keep the scalar and its quadratic classes fixed, and let the **complete first rational conic parameter** vary. The entire raw companion genus-one fibre has no point over that one rational function field. The proof untwists the fibre and uses the nonisogenous genus-one Jacobians of the two raw conic covers. It covers both finite and infinite candidate section values.

This does not exclude a rational point at any particular value of that parameter, any Ready-pole specialization, or a higher-genus base change. It supplies no original PointPair, detector point, or rank computation.
