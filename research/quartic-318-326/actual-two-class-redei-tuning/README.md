# Choosing auxiliary primes to pass two marked descent tests

This paper-level packet supplements the two-contact local cover and its
supported Selmer calculation. It shows that two independently adjustable
Rédei symbols allow the second auxiliary prime to meet both explicit Cassels
pairing tests, without dropping the earlier local contact conditions. Only the
tested Selmer subspace is covered. This is not a certification of the full
4-Selmer lift or a rational point, and does not furnish the auxiliary primes
numerically.
