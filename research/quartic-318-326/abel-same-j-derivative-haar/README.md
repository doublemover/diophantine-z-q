# Same-Jacobian Abel differential and exact target Haar scale

This directory contains the exact paper proof and its independent signed
mathematical review. This is paper evidence, not a native Lean theorem
about the original height and not a claimed CI result for the pending
source-only modules.

**Inputs.** The actual selected smooth compact modular curve and its
ordinary analytic period projection/cusp disks, the algebraic Jacobian
of that same curve and its own pointed Abel map over the chosen complex
embedding, and the original ordered differential frame (not a substitute
frame). The paper uses the following primary references:

* [Milne, Jacobian Varieties, Proposition 2.2](https://jmilne.org/math/xnotes/JVs.pdf#page=6), the isomorphism on differentials induced by that very Abel map.
* [Milne, Abelian Varieties, Proposition 2.1](https://www.jmilne.org/math/CourseNotes/AV.pdf#page=16), the exponential of the actual abelian variety with full lattice and differential the identity.

**Conclusion.** The derivative of the actual ordered Abel map in the
original period coordinates is the ordered form-evaluation matrix.
Constructing target Haar from the actual half-open fundamental lattice
box fixes the Euclidean chart normalization and the positive Hodge volume
factor. After cancellation of the actual upstairs hyperbolic densities,
the genuine regular sheets push the stated weighted source measure to
that target measure with multiplicity g!. A chosen arithmetic value is
not assumed regular. The curve's Jacobian is not the other abelian
variety used in the arithmetic comparison. Analytic uniformization,
algebraic Jacobian data and a native height theorem are not furnished
by this paper stage.
