# No odd-degree raw companion parametrization on the archived input-0 scalar

This paper uses the literal archived $\beta,\delta$ and the common double cover of the two source projections. A mixed root pair on one target and a full quadratic root pair on the other have pullback Weil pairing $(-1)^d$, where $d$ is the degree of the first projection. Rational nonisogeny of the two target Jacobians makes the same pairing trivial. Applying the argument in both directions forces both nonconstant projection degrees to be even.

This closes both raw bidegree-`(3,3)` strata, including the genus-five case that survived the earlier local reduction tests. It does not rule out even-even families or decide any individual rational companion, and does not change the shared source or certify any numerical witness.
