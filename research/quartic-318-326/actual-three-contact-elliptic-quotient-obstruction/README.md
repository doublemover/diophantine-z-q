# A controllable obstruction on an elliptic quotient of the actual three-contact cover

Both prime choices preserve the pointed genus-17 local conditions. Varying one
quartic residue sign toggles a Cassels pairing on a two-contact elliptic
quotient. One choice must give an everywhere locally soluble cover without a
rational point. The other avoids this particular test but is not shown to
have a rational point. The proof does not compute the auxiliary primes or
identify the obstructed branch numerically.
