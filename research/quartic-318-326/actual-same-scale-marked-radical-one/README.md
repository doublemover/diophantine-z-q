# A single marked radical line on a same-scale pair of original factors

This proof uses two roots already present in the original equations, both at
the first scale. The earlier cross-scale root pair is a different target.
The same-scale curve has exact normalized 2-Selmer dimension three, and one
admissible prime choice makes its radical precisely the marked line. This
gives full 2-primary Selmer corank one. A rational point on this pair follows
only if the explicitly pinned pointwise rank-converse preprint is used.

The proof retains the earlier sixteen local conditions in the construction.
It does not show a single rational point in all those local cells, solve all
the factor equations, compute the auxiliary primes or a numerical point, or
claim a completed Lean theorem.
