# A sparse ramified Heegner jet certificate at squarefree level 33

This exact test uses the genuine modular curve X₀(33), the semistable elliptic newform, and the two marked CM points of discriminant −35. Eight weighted relations on nine labels reduce the signed first jet to one differential value. That value is nonzero: if it vanished, symmetry would force eight zeros on a genus-three curve, where a nonzero regular differential has only four.

It is a nonzero certificate on a separate test curve. It does not compute a modular differential value or a witness at the level or twists required by quartics 318/326.
