# Positive marked Selmer controls on every allowed contact profile

The [positive family](ct-original-k0-positive-radical-profile-r1/STANDALONE-READY-FULL-MARKED-RADICAL.md) makes the whole marked Cassels character trivial, so the mark is in the image of 4-Selmer. It holds for each allowed six-contact profile on infinitely many numerical Ready poles with varying complementary squareclass. Together with the published negative controls, it shows that the contact profile alone does not determine the obstruction.

The separate [any-lift criterion for the first key 3 beta](ct-original-k0-3beta-any-lift-r1/EXACT-ANY-LIFT-FOR-FIRST-KEY-THREE-BETA.md) gives a certificate for membership without enumerating all second keys. An explicit alternate lift shows that the earlier Gaussian norm was necessary only for the specified lift, not for every lift.

Neither result proves that a constructed pole is an output of the original fold or gives a rational point. Independent signed reviews and exact arithmetic replays are included.
