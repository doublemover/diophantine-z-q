# A finite genus-trace criterion for the same-scale marked curve

This paper reduces an independent rank-one route to testing a specific
oriented trace at the prime 61. It uses a fixed semistable modular level
and a separately checked rank-zero auxiliary twist. A nonzero order-17
component at 61 would certify analytic rank one by the stated classical
results, without using the October rank-one converse.

No actual auxiliary prime choices or genus trace are computed. The
index and CM class count are still large; the paper does not assert that
straight enumeration is practical. Meeting the original simultaneous
local contact conditions with a rational point is a separate step.
