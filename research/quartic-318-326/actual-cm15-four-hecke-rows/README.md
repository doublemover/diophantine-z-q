# Four exact Hecke rows certify the nonzero CM15 jet

On the same separate X₀(32) test curve, four weighted Hecke rows on eight marked labels certify a nonzero ramified jet without solving the full matrix. The relation reduces the tested sum to a nonzero multiple of one differential value. On this genus-one curve the normalized differential has no zero, so that value need not be computed for the nonvanishing argument.

This is a checked sparse certificate for a test curve, not a sparse certificate or an anchor on the high-level quartic construction.
