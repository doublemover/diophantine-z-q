# An explicit nonzero anchor for the fresh-prime construction

One fixed marked CM point lies on the actual modular curve and has nonzero weight-two differential, proved by an exact Fourier tail bound. The existing fresh-prime conditions make its reduction supersingular, and let us avoid the finitely many primes where the reduction or nonzero value could fail. This needs no additional congruence condition on the selected fresh primes.

The anchor is not itself a selected Heegner contribution. A relation to the signed trace, and nonvanishing of that trace, are still missing. No conclusion is given for the already fixed historical prime.
