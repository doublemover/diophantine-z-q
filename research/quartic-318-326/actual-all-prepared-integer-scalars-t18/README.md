# A fixed first point for every prepared integer scalar

The [paper](author/ALL-PREPARED-INTEGER-SCALARS-T18-FIRST-AND-COMPANION.md) gives the exact native first point with fixed `t=18` for each already-prepared scalar at its own index, and an equivalent rank-free quartic test for the remaining native companion. It does not assert simultaneous Ready preparation at all integer inputs or produce a global companion. See the [signed independent review](cold/INDEPENDENT-ALL-PREPARED-INTEGER-SCALARS-T18-REVIEW.md).
