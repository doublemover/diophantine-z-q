# Two nonzero weighted Heegner traces for one original detector

For a fixed original Ready detector, a shared re-selection of auxiliary
primes keeps both exact selected Selmer eights and forces both
\(\chi_{17}\)-weighted Heegner traces to have infinite order.
The first proof constructs the initial graph and derives the exact
relative two-adic index. The successor adds shared reserves and
guarantees both weighted values for the same final prime.

**Both weighted points lie on the fixed curve \(E_{-17}\), not on
the moving target arms.** No nonzero unweighted trace, rational
mark, source anchor, or same-index four-point conclusion is proved.
