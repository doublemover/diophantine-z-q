# Full marked Cassels character on the original zero-direction cover

The [main paper](ct-original-k0-first-character-r1/ACTUAL-K0-FIRST-CHARACTER-AND-EXACT-LIFT.md) reduces the marked Cassels pairing against any admitted full 2-Selmer class to two quadratic-residue products depending only on its first squareclass. It gives an exact norm criterion for one specified lift, not a test for every possible lift.

The [pure-second result](ct-original-k0-pure-second-neutral-r1/ACTUAL-K0-PURE-SECOND-CASSELS-NEUTRALITY.md) and the [actual scalar support-limited computation](ct-actual-scalar-k0-supported-admission-r1/ACTUAL-SCALAR-SUPPORTED-K0-SELMER-CUT.md) are included with independent reviews and exact numerical replays.

This does not establish the required points, identify the full Selmer group on the fixed scalar, or finish the original forward proof. It is not Lean-verified.
