# Odd ordinary residue degree and an unmarked genus-slice test

Read [the exact odd-degree refinement](source/original-detectors-odd-ordinary-residue-degree-r1/ODD-ORDINARY-RESIDUE-DEGREE-PRESERVES-ACTUAL-SELECTOR.md),

Run 'sh verify.sh' to check the exact proof and review files.

On the symmetric original first arm one can reselect the shared final
prime within both original quadratic selection rows so the ordinary
CM residue degree at 2 is odd on that arm. Joint oddness requires
the explicitly stated additional companion prime residues and fixed
Rédei increment conditions. The exact selector's local marks and
Selmer eights remain unchanged, but a formerly fixed exact final
prime or higher residue class is not retained by this construction.

An actual unmarked reciprocal-j polynomial of one complete genus slice
would give the correctly normalized edge bit by a single norm
coefficient. In odd residue degree it gives that same bit by one
power-sum trace, without constructing the edge graph. No original
slice polynomial, normalized bit, unweighted trace, rank, or point
was obtained. The bounds and receivers should not be read as an
enumeration algorithm for the actual class field.
