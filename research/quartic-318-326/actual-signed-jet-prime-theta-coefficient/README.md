# The whole moving-prime jet as one prime-index coefficient

For the fixed mover and the fixed earlier choices in the actual same-scale construction, the signed jet is an exact indicated coefficient of a weight-5/2 ternary theta combination. The reduction accounts for all contributions, including the original genus signs and possible cancellation. It is not an evaluation of the coefficient.

The genuine marked differential values still enter the coefficient. The prime index must satisfy the exact original selection and both subsequent tail exclusions. Existing squarefree-index results do not by themselves supply a nonzero coefficient on that prime subsequence.
