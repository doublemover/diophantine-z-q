# The signed arithmetic comparison for the actual stalk pairing

The paper comparison fixes the same correction primitive, maps, local classes
and invariants. Classical arithmetic duality supplies exact annihilator
adjointness on the finite reduced 2-primary subgroups and gives an even
signed valuation defect. This does not assume finiteness of the full
Tate–Shafarevich group and does not prove any Mordell–Weil rank or a rational
point. This packet contains the paper proof and independent review, not a
compiled native module union; the receipt records the corresponding source
draft and the unresolved duplicate-declaration issue.
