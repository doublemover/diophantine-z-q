# Detecting the original signed class on one fppf test

This is a standalone classical argument for the two actual
directional lines of the same selected QM surface. Zero of the
corresponding Picard sheaf class is used only to obtain local
triviality on an affine fppf test of the literal dual numbers. The
argument reflects the signed additive coboundary by one linear
functional; it does not require global descent of a line
trivialization as native input.

The paper and standard-library Python control are exact immutable
author files. The control verifies 2,500 gauge rows over a concrete
faithfully flat test (F5[x]/(x^4)), and also verifies that
the test has no map over D to the original dual-number ring. It is not the
proof of the geometric assertion. No Lean source, hosted claim,
full PEL representability, or final quartic theorem is included here.

Run:

    sha256sum -c SHA256SUMS
    python3 -B replay_nilpotent_cover.py | cmp - replay.json

The preceding identified signed lines and normalized comparison are
in [the actual polarized columns](https://github.com/doublemover/diophantine-z-q/tree/a80b2c130d7c3beedd6454e305b5c7a56b34b463/research/quartic-318-326/actual-same-a-ext-polarized-columns).
