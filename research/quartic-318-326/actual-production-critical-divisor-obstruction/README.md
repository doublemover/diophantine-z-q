# Forced zeros on the actual supersingular locus

The sign conditions imposed by the actual mover constructions force a fixed set of complex-multiplication critical points to reduce supersingular. The differential is therefore not everywhere nonzero there, even after allowing compatible changes of the mover primes. This rules out the whole-locus nonvanishing shortcut, not the existence of an individual nonzero anchor or a nonzero signed first jet.
