# A degree-24 class-group certificate for one selected original detector companion

This package contains the frozen paper and its independent signed review. It proves a sufficient bound on a specific class-group eigenspace for rank one and the prescribed mark on one selected original detector companion. No class-group dimension, rank, or point was computed. The other arm and poles are not addressed.

Verify the exact contents with:

```sh
sha256sum -c SHA256SUMS
(cd author && sha256sum -c SHA256SUMS)
(cd cold && sha256sum -c SHA256SUMS)
```
