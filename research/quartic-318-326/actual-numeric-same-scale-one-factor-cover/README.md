# An exact rational witness for one same-scale contact factor

The example gives rational W,Y with W²−1/2399=bY² for b=111638485322809. It keeps one original common index and the sixteen inherited local cells, and has exactly the two stated new odd factor primes. The full directed-real replay and an independent local checker are included.

This is a witness for one factor. The same b is nonsquare at 23, so this example does not meet the full saturated-prime conditions. It supplies neither the other same-scale factor nor a joint four-pole witness.
