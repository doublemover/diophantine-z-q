# An order-three receiver for the same low-level trace

At 13 the same genus trace has an exact finite rank detector with a three-element target. Its receiver is an explicit cubic over a fixed finite field, and its arithmetic Frobenius translations are directly replayable. A nonzero signed trace would give the stated nontorsion and rank consequence. This does not construct the marked source fibre, evaluate the trace, or test the missing moving contact cells.
