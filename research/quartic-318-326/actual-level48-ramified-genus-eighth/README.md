# Rational eighth divisibility of the original detector trace

The exact raw, unweighted level-48 trace on either selected detector twist under the stated hypotheses is a rational eighth multiple. The proof combines four genuine genus characters with the same-map height comparison and compares named two-torsion in the two retained ramified reductions. It excludes a mark on the rational quarter, without requiring any of the shorter comparison twists to have the selected Selmer group.

This package contains the author proof and standalone independent review. It does not evaluate a trace, assert positive or zero rank, or produce the rational mark. Sixteenth divisibility and numerical reference-operator tables are separate.
