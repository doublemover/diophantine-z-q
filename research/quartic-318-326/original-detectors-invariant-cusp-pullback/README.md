# A cusp-only modular function for the ordinary binary Heegner edge phase

Read [the exact proof](proof/ATKIN-INVARIANT-CUSP-PULLBACK-OF-ORDINARY-EDGE-PHASE.md)
and the [signed independent review](independent-review/INDEPENDENT-ATKIN-INVARIANT-CUSP-PULLBACK-REVIEW.md).
Run 'sh verify.sh' for the exact standard-library Laurent replay.

A fully Atkin–Lehner-invariant modular function on X₀(6), with poles
only at cusps, gives the previously established ordinary matched-edge
bit after summation on a Frobenius-stable packet and division by 2²⁴.
The verified identity also gives divisibility at the normalized source
cusp for its constant and specified weighted principal-part sums.
The proof contains a separate identity for the level-2 involution alone.
No theta-cusp transport, integrality of a divided modular form, actual
detector bit, target rank, or rational mark is claimed here.
