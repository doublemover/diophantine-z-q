# Conditional normalization for a different imaginary discriminant

This note gives only the normalization once the same-test-vector
and marked-specialization hypotheses have been established for the
new field. It is not part of the independently accepted fixed
m=455 calibration and supplies no new compatible trace witness.

The older fixed-level odd detector note wrote out the ratio
for one fixed m=455. For different compatible m, with the
literal same F, use [Cai–Shu–Tian Theorem 1.10](https://arxiv.org/pdf/1408.1733)
before taking that ratio. The conductor is d, the quadratic
discriminant is −m, and u=1 (the class-group factor from Q is
trivial, units ±1 in both orders). There are no level/
discriminant places common to remove. Thus the factor in
|P_d(F)|² is √m·d, where D₁=−d and D₂=md are the two
fundamental discriminants. This requires m>0 squarefree,
m≡23 mod24, (m/53)=−1, d>0 squarefree, d≡11 mod24,
(d/53)=−1, gcd(md,2·3·53)=1, gcd(m,d)=1, and all d primes
split in Q(√−m) for the stated literal Heegner construction.
One must use its own compatible CM orientation and
actual finite specialization; the same numerical d in an
unrelated quadratic field is not a substitute.

The fixed ST weight forms keep their same coefficient type.
For the CST comparison additionally supply the exact same test
vector F for the new oriented optimal embedding and the actual
geometric specialization to those labeled marked classes. Local
sign compatibility by itself does not supply those identifications. The two
central values contribute respectively |D₁|^(−1/2) and
|D₂|^(−1/2), with no common-level prime factors.
Their product cancels √m·d exactly. Hence the modulus-13
reference constant 10 in the weighted coefficient note
is also the same for these different compatible m, not
an m-dependent height or period correction. The compute
size is controlled by md, so a large auxiliary m may
still make the algorithm impractical. This is no freedom
to replace m if the original proof has already prescribed it.
