# Exact cancellation of an entire test jet

On the separate X₀(32) test construction, the exact signed local sum vanishes modulo 5 for the prime 3881 even though each of its 78 actual paired contributions is nonzero. A second prime with the same tested residue and level-orientation conditions gives a nonzero sum. The replay accounts for all terms; the independent calculation checks their multiplicities.

This is a counterexample to inferring a nonzero sum from individually nonzero pairs. It does not compute the 318/326 trace or imply a characteristic-zero vanishing.
