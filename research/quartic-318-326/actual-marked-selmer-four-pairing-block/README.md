# A nonzero pairing block with the marked class still in the full radical

One can keep the marked class in the full 4-Selmer image while forcing a
nonzero alternating block on two other directions. This proves that the
pairing has rank at least two, not that the elliptic curve has rank two.
The separate conditional reduction explains why isolating the marked line in
the entire normalized radical would suffice for corank one. It does not
establish that line or invoke an independently certified rank converse.
