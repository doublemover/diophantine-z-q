# The two original KS classes under the same polarization

The exact paper and signed independent review compare both original
ordered cotangent connecting classes with the actual polarized tangent
points on one finite separable residue test. The source is Yuan's
connecting-map definition and Lan's signed logarithmic description of
the differential of the polarization. At 5 this compares full columns,
not a determinant test. No native theorem or new rank conclusion is
included.
