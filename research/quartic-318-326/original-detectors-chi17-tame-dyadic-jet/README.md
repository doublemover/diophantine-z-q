# An exact tame ordinary readout for the weighted genus half

Read the [general logarithm and target precision](base-receiver/DYADIC-JETS-FOR-ACTUAL-GENUS-HALF-LOG.md),
the [tame one-jet refinement and exact reference](tame-receiver/ONE-TAME-ORDINARY-JET-FOR-THE-ACTUAL-DYADIC-LOG.md),
and the [independent review](independent-review/INDEPENDENT-TAME-DYADIC-ONE-JET-REVIEW.md).
Run 'sh verify.sh' to replay the canonical lifting and both genuine
reference genus-half traces, using the Python standard library.

This package reduces the production dyadic criterion to one tame
level-3 class-polynomial jet (or an equivalent logarithm aggregate).
It proves that exact **oriented ordinary mod-2** inputs, if supplied,
determine all higher required bit precision. Only the named
quadratic/genus fields split at 2; the full Hilbert class field
need not, and the calculation uses its unramified Frobenius.

The complete numerical demonstration is for the genuine CM reference
D = −119. It evaluates two degree-five Frobenius orbits and checks both
half-log depths exactly. That reference is not a selected original
detector pole. No tame packet, jet, unweighted value, rank, or rational
mark is supplied for either selected production twist.

The papers' unchanged archival references identify the exact modular
coordinate donor from Colò and the complete reference-orbit and
weighted-trace papers. No donor code or file is required by the replay.
