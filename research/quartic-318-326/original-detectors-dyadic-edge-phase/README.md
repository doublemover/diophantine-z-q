# One binary ordinary CM edge moment for a selected detector arm

Read [the proof](proof/FIRST-DYADIC-HEEGNER-BIT-IS-AN-ORDINARY-EDGE-MOMENT.md)
and the [independent review](independent-review/INDEPENDENT-ORDINARY-DYADIC-EDGE-BIT-REVIEW.md).
Run 'sh verify.sh' for exact standard-library replays.

For each exact selected arm, a single nonzero characteristic-two
ordinary CM edge aggregate would give a nontorsion unweighted trace.
It uses reciprocal source/target j-invariants of actual matched
horizontal 3-edges from a genus half. No high dyadic precision or
full level-48 coordinate is needed by the criterion. A zero bit is
inconclusive; counting both orientations or giving only the unmarked
Hilbert class polynomial does not supply the matched aggregate.

The numerical bits in the replay are for the complete genuine
D = −119 reference only, not a selected original pole. No bit, rank,
unweighted value, or rational mark is calculated for an actual
selected production twist. The proof records exact donor references;
none are needed to run the finite polynomial and field replay.
