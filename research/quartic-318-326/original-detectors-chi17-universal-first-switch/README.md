# A selector-preserving first-arm switch for an original detector

Read the [exact proof](source/original-detectors-chi17-universal-first-switch-r1/ORIGINAL-DETECTOR-UNIVERSAL-FIRST-ARM-SWITCH.md)
and [signed independent review](independent-review/INDEPENDENT-UNIVERSAL-FIRST-ARM-SWITCH-REVIEW.md).
Run `sh verify.sh` to check all hashes and replay both literal graph profiles.

Fix an actual Ready detector from the original common-index linear Gaussian
construction. Without changing that pole or any source-side primes, the proof
selects downstream helpers so that all three or four final-prime switch bits
preserve the first Selmer eight. For each switch row a companion Schur extension
preserves the second eight and the same literal mark at one shared final prime.

If the one fixed reference bit u(d) is 1, a whole reduced CRT class of final
primes has a first-arm nontorsion Heegner trace and the first rational mark.
The companion rank is not proved. The reference bit can instead be obtained
from one actual unmarked CM genus slice for a separate auxiliary prime
split at every genuine factor of d. Neither the bit nor that slice is supplied,
and no production rank or pair of rational points has been obtained.

The underlying source profile is pinned via the [original Gaussian source proof](https://github.com/doublemover/diophantine-z-q/blob/97adcaf7e8331759afbced0339d1a267ac8bf5c4/research/quartic-318-326/actual-linear-denominator-prime-route/original-linear-denominator-prime-route-r1/LINEAR-GAUSSIAN-PRIMES-TO-ORIGINAL-READY-POLES.md).

The machine replay checks only the finite graph identities, not CM coefficients or ranks.
