# An everywhere-local genus-one fibre for the original scalar

The main paper preserves the original PointPair equations, writes them as an open Kummer surface, and identifies a single explicit quartic fibre at the frozen admissible scalar index. A rational point on this fibre would give both requested nonzero ordinates for that scalar. Independent arithmetic confirms the fibre has no rational point at infinity, and the proof constructs local points in the useful open at every place.

The fibre is an unconditional reduction, not a rational point or a four-pole realization. The generic absence of a section is not a nonexistence theorem at the fixed original scalar. The exact replay and independent review are included. No Lean claim is made.
