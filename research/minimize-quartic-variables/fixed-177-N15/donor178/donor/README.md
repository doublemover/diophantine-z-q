# 180 variables, N = 15: complete quartic and proof

**Open [quartic180-N15.txt](quartic180-N15.txt) for the actual polynomial**, including every integer coefficient. It is 82,777 ASCII bytes and has SHA-256 `51d39c44672fa8a1a15940357a525babfa169794f460da30b5f186cd3e584d4a`. The free input is x1; all other 179 coordinates are rational witnesses. Under the same arithmetic hypotheses as the two source constructions, its projection on x1 is exactly the integers. This is not a claim of an unconditional definition over the rationals, a minimum arity or a Lean proof.

The shortcut is one reused coordinate. A cubic scalar-pole formula frees a square-storage slot, which now holds the inverse needed for a saturated scalar. The three actual contact measurements, including both field components and the two signed comparisons to z=X²+48, remain. Only four of 152 quadratic residuals change. The parameter values of the former 180 construction do **not** apply to this coefficient file; this is a distinct polynomial specialized at 15.

* [PROOF.md](PROOF.md) covers both directions, including arbitrary rational inputs with 149 in the denominator and the integer input zero. In the forward construction, primes of **negative** odd scalar valuation need preparation just as much as primes of positive odd valuation.
* [QUADRICS.json](QUADRICS.json) gives the 152 equations, [POLYNOMIAL.json](POLYNOMIAL.json) all 3,253 distinct expanded monomials; 365 bits is the largest absolute coefficient. [TRANSFER.json](TRANSFER.json) records the actual coordinate identification.
* `python -B verify.py` uses standard Python alone to reconstruct the literal, the four changed scalar rows and both guards, and check the scalar arithmetic. `python -B replay_all.py` additionally checks the complete table against the two frozen predecessor sources, uses SymPy for an independent symbolic test, and rebuilds the literal in a clean temporary directory. No repository, network, solver or Lean installation is needed. The independent arithmetic review is included next to the files it binds.
