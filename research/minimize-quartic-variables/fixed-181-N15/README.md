# A fully written 181-variable quartic at N = 15

Open **quartic181-N15.txt** to inspect the actual integer polynomial: 92,690 bytes, no symbolic parameter. Search for x1 to see the input (the other 180 variables are rational witnesses). QUADRICS.json gives its much shorter sum-of-squares description. POLYNOMIAL.json gives all 3,338 monomials as signed integer coefficients and sorted variable indices. The largest coefficient has 307 bits. Both tables and the literal describe exactly the same polynomial.

Under the *same* arithmetic inputs as the included three-contact 182 construction, the projection equals the integers. Read **PROOF.md** for the complete forward and reverse transfer. The essential arithmetic feature is that the new scalar has 149-adic valuation exactly 31 even on inputs with powers of 149 in the denominator; the resulting divisibility by 149⁶⁶ suffices at N=15. The construction still depends on the donor's stated arithmetic theorems/suppliers. No unconditional definition or Lean certification is claimed.

Two details when reconstructing the argument:

* On every integer input, reduce the fraction R for that particular integer and prepare the scalar witness at **both numerator and denominator primes** where the valuation of R is odd. A negative odd valuation cannot just be ignored: the reference point and then the scalar point are chosen deeply enough there to make the valuation of the actual pole input R³W² nonnegative. The same old existence theorem allows arbitrary finite-depth conditions; only after these are prescribed are the thirty comparison primes chosen. X=0 is included.
* The frozen TRANSFER.json has a misleading descriptive field named "a": it contains a stringified solver result left by the original generator. It is not an arithmetic constant or an input to verification. The interpolation center is **−705023/51**, forced by the inverse row itself. The gauge exponents and variable bijection are the separate structured fields. The exact original table, literal and metadata bytes have been preserved.
