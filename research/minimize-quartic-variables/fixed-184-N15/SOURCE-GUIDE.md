# Verifying the fixed 184
Run `python -B verify.py` to reverse the coordinate weights, compare the scalar/reference, aggregate and factor rows with the donor formulas, square the residuals and reproduce the literal file. The verification needs only Python 3 and this folder. The intermediate 188 argument is printed as PROOF188.md; its hashed intermediate coefficient tables are not duplicated here. Both use the v62 effective arithmetic assumptions and N=15, not the v74 unspecified cutoff. The two independent mathematical reviews bind the source digests of both stages. The word “private” in the transfer metadata denotes an internal coordinate of this polynomial, not hidden source data.
