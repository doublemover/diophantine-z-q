# Homogeneous to affine norm witnesses

One source module is added. Over any characteristic-zero field, a nonzero homogeneous solution to z²-a*x²-b*w²=0, with a nonzero, constructs an affine norm witness u²-a*v²=b. For w nonzero the proof divides coordinates by w. For w=0 it proves a is a nonzero square and constructs the split norm witness explicitly. The a=0 elementary branch remains separate.

All1332 predecessor sources and their relative order are retained exactly. The new leaf has one experiment-root closure, importing only Mathlib.Tactic. No squarefree/CRT/centered-root or full descent layers are bundled.

Source/API review is not Lean acceptance. No local Lean was run. The claim does not prove local-global existence, auxiliary-prime compatibility or simultaneous elliptic realizations; all actual conditional arithmetic hypotheses are preserved.
