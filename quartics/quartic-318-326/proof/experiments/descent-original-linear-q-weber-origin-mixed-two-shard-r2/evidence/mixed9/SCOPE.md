# Actual stock mixed addition: same abscissa, first and second-order expansions

The source-only terminal does not reimplement the secant or substitute
another point or valuation ring. The seven selected dependencies are
exact strict Torsion16r2 owners, especially mixed_stock_coordinates on
the original stock curve with its literal IntegralData. The two
remaining sources are the exact first-order polynomial calculation
and its application to the exact X,Y output of that checked theorem.

The first expansion computes a+2*b*s+s²*C for the actual abscissa of
the input origin-kernel point P added to the literal finite point
(a,b). If this same origin parameter s=tCoord(P) is supplied as
t²*d in the same valuation ring, the very same output has abscissa
a+t²*C'. Zero origin is handled separately, with the same x,y.
The second-order statement is conditional on the exact parameter
witness; it does not assert the selected Gaussian scalar automatically
produces that witness. Formal Laurent construction, global derivative,
rational degree, CM, conductor and FT are outside this selection.

Only the nine-module terminal is requested as a planning scope; no
baseline reuse, Lean build, remote writes, dispatch, or acceptance
is carried out by staging.
