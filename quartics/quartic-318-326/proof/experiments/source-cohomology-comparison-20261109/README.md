# Source cohomology comparison for the five actual quotient maps

This packet constructs the actual canonical map
H^n(E, f_*O_C) → H^n(C, O_C), proves its degree-zero bijectivity and degree-one injectivity, and therefore proves injectivity of each actual H^1(E_i,O_E_i) → H^1(C,O_C) into the same original source group.

The map is not an arbitrary injection and the codomain is not redefined. It is exact inverse-image transport on Ext, the original inverse-image/direct-image adjunction counit, and the canonical comparison of original constant integer sheaves. Naturality and the degree-zero inverse-adjunction formula are proved.

The substantive general argument in AdjunctionExtOneInjection318 proves injectivity of the Ext^1 mate when the left adjoint is exact and the right adjoint is only left exact. It uses an injective embedding, both actual cokernel sequences, the induced cokernel monomorphism, Ext connecting classes, and adjunction. Thus no false all-sheaves exactness hypothesis is smuggled into a finite Zariski map.
