# Simultaneous exhaustive root graphs

All specialized roots of a monic separable polynomial over the true polynomial base localization extend simultaneously to distinct analytic graphs on one open neighborhood. These graphs exhaust every root over every point of that neighborhood by exact degree cardinality, without excluding any independent candidate root or assuming original-image membership.

This is a local theorem on the independently defined entire root locus. The index set is all roots over the center, not selected original-image sheets. Every nearby fiber has exactly the same monic degree; finite noncollision gives an injection and equality of cardinality gives surjection. No global covering trivialization, global image equality, rational selected factor or PEL descent is asserted. All162 predecessor modules are exact copies.
