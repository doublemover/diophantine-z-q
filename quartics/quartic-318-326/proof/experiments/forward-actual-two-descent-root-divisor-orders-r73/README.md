# Primitive modular-root extraction

One pure source module is added. A primitive integer solution modulo p squared to z squared - a x squared = p B w squared, with p prime and p not dividing B, produces a square root of a modulo p. The proof includes p=2 and p dividing a; the required nonzero denominator is proved, not assumed.

All 1330 predecessor sources and their relative order are retained exactly. The new module has a single experiment-root closure. No local-to-primitive extraction, squarefree normalization, CRT assembly, full Legendre induction, auxiliary selection or local-global principle is supplied. No affine-transfer module is included.

Source/API review is not Lean acceptance. No local Lean was run; hosted strict compilation and recursive audit remain required. All existing conditional actual arithmetic hypotheses and realization gaps are unchanged.
