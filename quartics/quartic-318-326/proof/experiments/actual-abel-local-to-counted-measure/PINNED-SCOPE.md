standalone proper countable covering donor is previous static source,

The theorem takes compact source (actual ordered X(C)^g), open good
target V in the same target, actual local homeomorphism over V, and
actual fibre cardinal d. It only asks for a pointwise local weighted
pushforward on some open injective neighborhood of each actual source
point. Existing local laws need not share target charts and no countable

For each genuine evenly covered patch, take one source point per
inverse branch and one of the already constructed local laws at that

at each point of the source intersection. The common target has its
entire actual fibre in the chosen chart for that branch, by injectivity
of the covering branch. Conversely the chosen chart has no other
preimage there, by its own injectivity. Thus the restrictions of all
the local laws give exact true branch pushforwards over a single
patch; all sheets are counted without any missing points.

two null complements give the global formula. In the proposed actual

comparisons separate; no assumption that a selected arithmetic center
