# Remaining scope

This packet proves an exact named-function local comparison, conditional only on the stated field and characteristic-zero structure. It does not construct a native principal-divisor homomorphism, an associated-divisor sheaf identification, global translation, theta group, Weil pairing, Cassels–Tate pairing, or rank proof. Actual all-point off-support units are the next join. Structural admission is not kernel validation.
