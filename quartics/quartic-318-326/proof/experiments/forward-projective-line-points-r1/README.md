# Draft: actual projective-line complex points

This is an unfinished continuation, not a frozen or accepted proof packet.
The three draft modules construct actual base-preserving Spec-valued points of
ProjectiveJLine318.scheme, cover all field-valued points by its original algebraic
charts, identify its finite and infinity points with a one-point parameter, and
compare the natural Euclidean chart topology with the independent sphere.

The point definitions use genuine scheme morphisms, not only homogeneous tuples.
The topology is defined from the two original algebraic evaluation maps, not by
transport from the modular source. Source checks are in progress. The eventual
analytic-manifold and exact original compact-source consumer comparisons are not
yet implemented. No arithmetic analytification functor, algebraic j-map or PEL
realization is claimed.

The topology module imports SphereInversion318 from the preceding complex-atlas
continuation. That exact predecessor and its acceptance will be pinned before
this packet can be frozen. No shared manifest change or baseline promotion.
