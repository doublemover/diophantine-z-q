# Finite unit CRT and Dirichlet prime construction

One native-only source is added. Given a finite family of pairwise-coprime nonzero moduli and unit residue classes, it constructs a prime above any supplied natural bound in every residue class. The assembled CRT class is proved coprime to the product; that condition is not an additional hypothesis. The proof uses the pinned native CRT and primes-in-progressions theorem, including the empty family/modulus1 case.

All1346 predecessor source bytes and order remain unchanged. This is a one-root strict checkpoint. Actual local p-adic unit classes still come from separately checked/proposed producers; this source alone does not construct those inputs or establish compatibility at the new prime. No global anchor, full ternary induction or elliptic realization is claimed.
