# Actual affine line descent from coalgebras

For any faithfully flat affine ring map, genuine scalar-extension coalgebra
data whose covering module is the actual sections of a line descends to an
actual line on the original affine base. Its actual scheme pullback recovers
the original covering line. Finite presentation, flatness and rank one are
descended explicitly, then full principal-open frames are constructed.

Five new sources and one unchanged affine-line-model producer passed a fresh
six-source strict Lean 4.35.0 replay and a private-inclusive recursive audit
of 40 declarations, with no warnings and only `propext`, `Classical.choice`,
and `Quot.sound`. The 62 baseline predecessors were reused
from verified artifacts, not rebuilt. Source acceptance is separate.

This does not convert geometric overlap data into coalgebra data or complete
arbitrary-scheme/fppf object descent. See `APPLICATION.md` and the bound
`validation/receipt.json` for the exact original object and map comparison.
