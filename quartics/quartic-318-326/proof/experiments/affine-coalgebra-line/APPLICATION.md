# Actual rank-one sheaves from faithfully flat coalgebra descent

Five new sources consume one unchanged original affine-line-model producer.
The source order, exact copies and pinned original baseline closure are bound
by intake and dependency receipts. This is a coalgebra-input theorem, not a
claim that geometric overlap descent has already been converted to coalgebras.

1. **Finite presentation descends.** For a genuinely faithfully flat R-algebra
   S and any actual R-module M whose actual S tensor extension is finitely
   presented, `FaithfullyFlatFinitePresentation318.descent` first obtains a
   finite free surjection onto M. The actual tensor of its kernel is identified
   with the actual base-changed map's kernel by `LinearMap.tensorKerEquiv`.
   That kernel is finitely generated by finite presentation. Faithfully flat
   finite-generation descent then gives the original finite presentation.
   The quantified rings and modules are arbitrary; no Noetherian or domain
   assumption is introduced.
2. **Actual line module.** `FaithfullyFlatLineModule318.properties` takes a
   specified S-linear isomorphism from the actual tensor extension of M to
   the actual affine section module of the input `Line`. It consumes the
   unchanged producer's finite-presentation, flatness and all-prime rank-one
   facts for exactly that original section module.
3. **Full prime coverage.** Flatness descends through the genuine faithfully
   flat tensor theorem. Rank one is proved at every base prime by the
   surjectivity of the full map of prime spectra and actual stalk-rank base
   change. No selected component, field point or generic-rank substitution
   is used. This includes arbitrary nonreduced base rings.
4. **Actual line reconstruction.** `AffineRankOneLine318.line` is literally
   tilde of the original reconstructed R-module, with a chosen principal
   neighborhood at every prime. The actual tilde unit transports the module
   properties to its original affine sections. The existing exact principal
   localization/frame theorem supplies actual unit-sheaf isomorphisms, and
   the full cover inequality is proved pointwise.
5. **Exact coalgebra input.** `AffineCoalgebraModule318.Data` is precisely
   Mathlib's coalgebra category for the original extension/restriction
   adjunction. It includes actual coaction, counit and coassociativity proofs.
   `comonadicExtendScalars` supplies the equivalence under the explicit
   faithfully flat ring-map hypothesis. No overlap-data effectiveness axiom
   or unavailable geometric stack theorem is assumed.
6. **Original descent comparison.** `moduleIso` is the underlying isomorphism
   of the actual comparison-equivalence counit. `coaction_compatibility`
   records its exact original coaction equation. `unique_morphism` proves
   existence and uniqueness of every original base module map from an actual
   coalgebra-compatible map between its scalar extensions.
7. **Scalar actions reconciled.** In `AffineCoalgebraLine318`, the actual
   chosen algebra structure and categorical scalar extension are reconciled
   through unchanged `ScalarExtensionTensor318.tensorEquiv`. The covering
   module is explicitly identified with the original input line's sections,
   rather than with an unbound isomorphic vector space.
8. **Actual original line consumer.** The reconstructed object is an actual
   `Line` on Spec R. Its actual `LineSheafPullback318` along the original
   Spec of the algebra map is isomorphic to the unchanged covering line.
   The comparison factors are the unchanged canonical `TildePullback318`
   comparison, actual tilde image of the coalgebra module isomorphism, and
   the original input line's tilde-Gamma counit. Their direction is recorded
   by `pullbackIso_hom`. The theorem is available for every faithfully flat
   affine map, including those that occur as affine fppf covers.
9. **Boundary and next consumer.** Geometric double/triple-overlap data has
   not been converted into this coalgebra input. The relevant pinned
   `DescentDataAsCoalgebra` and `ModuleCat.Descent` source headers explicitly
   retain that comparison as TODO. Arbitrary-scheme gluing, effective fppf
   descent of the actual line stack, identification of the naive relative
   quotient with its associated sheaf, degree zero, representability,
   Jacobians, polarization and isogeny remain outside this packet.
