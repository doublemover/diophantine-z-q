# Primitive shared-prime ratio extraction

One native-only source is added. From primitive integer mod-p-squared data for z²-p*a*x²-p*b*w² and p not dividing the first residual coefficient a, it constructs a modular square root of -b/a. Both coefficients have a displayed p-factor; only a is assumed a unit. The second residual coefficient may be nonunit, so the resulting square may be zero. A Jacobi-value1 application must separately establish nonvanishing.

All1349 predecessor source bytes and order remain unchanged. This one-root checkpoint does not supply actual primitive residues, selected-prime local values, finite reciprocity assembly or a global witness. The reviewed3-adic specialization and bad-prime applications remain separate consumers. No new hypothesis is inserted into any old theorem.
