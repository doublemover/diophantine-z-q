# Two independent stock coordinate foundations

One packet, two optional **separate** selectors. Recommended immediate
scope is the 5/0 valued reciprocal pole alone. Selecting the other 3/0
as a separately named shard is also valid, but there is no dependency
on it and no combined target. Neither selector uses verified-baseline
artifacts or reuse.

* ValuedPolynomialPole: four exact strict ordinary-slope donors and one
  source-only endpoint. For an actual valuation subring V and an
  evaluation point outside V, polynomial evaluation is injective and
  the same evaluated A/B is integral if deg A ≤ deg B and B ≠ 0.
  It uses the inverse and the reversed leading coefficients in the same
  residue field. An actual Gaussian scalar having an origin pole is
  a separate, broader application not selected in this packet.
* ResidualDegreeOne: three source-only modules with stock Mathlib imports
  only. From a canonical coprime quotient of max degree ≤ p, both
  zero derivatives, a nonconstant literal abscissa, and the cubic
  ordinate relation, it produces this same degree-one characteristic-p
  root coordinate pair. It does not establish stationarity, the cap
  or nonconstancy of any actual scalar, or classify the four units.

The theorem sources are exact frozen bytes. The two project import
closures are disjoint; 8 physical sources do not imply an 8-source
request. No complex uniformization, Height49 or origin-arc dependency.
This archive verifies structural/source provenance only, not Lean.
