# Actual original line automorphism groups

Four new sources use two unchanged original-global-constant producer copies
to close imports against the pinned 1,837-source baseline. Copies are not
additional results; source acceptance is separate from compiler evidence.

1. **Actual objects.** The input is an original `LineSheafClass318.Line X`
   and an actual module-sheaf automorphism. No automorphism of a class label
   or a replacement one-dimensional vector space is substituted.
2. **Original local frames.** `localScalar` compares the same original frame
   with its transport by the actual automorphism on every original subopen.
   Its value is an actual unit, with actual inverse, not just a nonzero number.
3. **Frame independence.** `localScalar_action` proves the actual action on
   every local section. Faithfulness of the actual rank-one frame proves
   uniqueness and independence on all common subopens.
4. **Actual restrictions and cover.** The original frame-gauge restriction
   identity proves compatibility in the actual structure-unit sheaf on the
   full original frame cover. No opens or overlap conditions are discarded.
5. **Global scalar.** The actual unit-sheaf gluing theorem constructs a
   global unit. `scalar_restrict` and `scalar_subopen` bind it to the original
   local coefficients. Actual module-sheaf separatedness proves its scalar
   action on every open and every original section; uniqueness uses the same
   full cover.
6. **Actual inverse.** The inverse construction is the unchanged earlier
   `ModuleScalar318.map` on the original module sheaf, applied to a global
   unit and its inverse. Both actual sheaf-map inverse equations are proved.
7. **Group equivalence.** `equivalence` proves both inverse laws and the
   multiplication law for the actual categorical automorphism group.
   The classification is an actual multiplicative equivalence with global
   structure units, not just an existence statement about some scalar.
8. **Original source consumer.** The unchanged source-global-constant theorem
   identifies the original structural Q map with all actual global regular
   functions on the original complete contact source. `ContactLineAutomorphisms318`
   composes the actual unit-group equivalence with this original ring
   equivalence. `original_action` retains the exact structural rational scalar
   action on every original open and section for every original line.
9. **Boundary.** This does not assert universal `p_* O = O`, general base-change
   compatibility of global functions, or triviality of every rigidified
   automorphism in arbitrary families. Pullback compatibility, effective
   rigidified descent, degree zero, representability and a Jacobian remain
   further work. No rational point of the original source is assumed.
