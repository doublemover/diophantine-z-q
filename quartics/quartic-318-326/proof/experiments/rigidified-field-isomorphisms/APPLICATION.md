# Actual rigidified isomorphisms and original relative classes

Four new sources use eighteen unchanged producer copies to close imports
against the pinned original 1,837-source baseline. Copies are not additional
results; source acceptance is separate from compiler evidence.

1. **Actual automorphism pullback.** Under bijectivity of the original
   scheme appTop map, the actual original line automorphism pullback is
   bijective. The lift uses the actual global-unit classification and its
   proved compatibility with the original appTop map.
2. **Different original lines.** Injective appTop also detects equality of
   actual isomorphisms between two original lines, by composing with the
   actual inverse and using automorphism faithfulness. No class label is
   substituted for a module-sheaf morphism.
3. **Specified rigidifications.** `CompatibleIso` stores an actual isomorphism
   of the two original module sheaves together with its equality against
   their two specified actual trivializations after the original pullback.
4. **Exact correction and uniqueness.** Bijective appTop lifts the precise
   automorphism comparing a given pulled-back isomorphism with the two
   trivializations. Composing that lift with the original isomorphism gives
   compatibility. Injective appTop and cancellation prove uniqueness of the
   actual compatible isomorphism.
5. **Actual class equality.** The genuine original class equality theorem
   supplies an actual underlying sheaf isomorphism. Thus equality of the
   original line classes is equivalent to existence of a compatible
   isomorphism, with the global-section hypothesis explicit.
6. **Original quotient by base lines.** The existing actual section-kernel
   equivalence proves that equal original relative classes of rigidified
   lines are equal original line classes. This kernel and quotient contain
   all relative line classes, not a degree-zero subgroup.
7. **Complete naive classification.** Every original relative class has an
   actual section-rigidified representative. Two such objects represent the
   same class if and only if exactly one actual compatible isomorphism
   exists. Objects themselves are not claimed to be literally equal.
8. **Exact contact-field consumer.** The original whole field-base-changed
   source, original structural map and previously constructed contact
   section are used without replacement. The proved actual field-family
   constants plus the section identity make its actual appTop bijective,
   discharging the generic hypothesis. All original relative classes and
   all actual lines on this full field family are covered.
9. **Boundary.** This classifies the original quotient before sheafification
   over that field family. It does not assert that every associated fppf
   sheaf section over the field already has a representative there, nor
   effective descent over arbitrary test schemes. Arbitrary-ring universal
   pushforward, degree zero, representability, a Jacobian, norm, polarization
   and isogeny remain further work. No Q-rational point is assumed.
