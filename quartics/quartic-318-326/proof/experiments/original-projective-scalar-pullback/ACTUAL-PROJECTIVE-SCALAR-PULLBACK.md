# Universal scalar pullback of the original projective j-line

The source calculation is on the original
\(\operatorname{Proj} R[X_0,X_1]\), not a new projective model or a
second chart identity hypothesis.

1. Each affine scalar square uses the actual \(S\)-algebra
   isomorphism \(S[T]\simeq S\otimes_R R[T]\). Its two projections
   send an \(S\)-scalar to the same constant and an old polynomial
   to coefficient extension with \(T\) unchanged.
2. The canonical Proj coefficient map has preimage \(D_+(X_i)\)
   equal to \(D_+(X_i)\) on the changed source, because the
   literal homogeneous coordinates are unchanged. The verified
   chart identity and these ranges give actual chart pullbacks.
3. The existing full two-chart cover and the scheme-local
   pullback theorem give the projective universal property.
   The maps on both charts come from the same Proj; no new
   transition map or scalar compatibility is supplied.
4. For a genuine constant extension of the compact source, the
   new modular map is defined by this universal property and
   the exact compact j-square follows by pullback cancellation.

The standard paper result is scalar base change for relative Proj
([Stacks 01NS](https://stacks.math.columbia.edu/tag/01NS),
[Stacks 01OE](https://stacks.math.columbia.edu/tag/01OE)).
The source candidate explicitly proves the property via the given
two-chart model. No genus, selected geometric factor, proper modular
comparison, or stable Hodge lattice is inferred here.
