# Actual pullback of original line automorphisms

Three new sources use nine unchanged producer copies to close imports against
the pinned original 1,837-source baseline. Copies are not additional results;
source acceptance is separate from compiler evidence.

1. **Original module maps.** The scalar endomorphism is exactly the existing
   `ModuleScalar318.map`, on the actual original scheme module sheaf.
   No replacement module or scalar-action convention is introduced.
2. **Pushforward scalar.** The actual direct-image module action and the
   actual scheme restriction naturality prove scalar compatibility on every
   original open and section. There is no affine-open restriction.
3. **Pullback scalar.** The actual module-sheaf pullback/pushforward adjunction
   transports that equality to the actual pullback functor. This applies to
   arbitrary module sheaves without flatness or local-freeness assumptions.
4. **Original line scalar.** The unchanged global-unit classification of
   actual original line automorphisms is used. Its scalar pulls back by the
   actual original scheme `appTop` ring map, for the exact original line
   pullback and actual functor image of the automorphism.
5. **Faithfulness.** Injectivity of that actual `appTop` implies injectivity
   of the actual pullback homomorphism on original line automorphisms.
   This hypothesis is displayed, not inferred from arbitrary base change.
6. **Rigidification.** An actual isomorphism from the pulled-back line to the
   actual unit module sheaf, and compatibility of an actual automorphism with
   it, imply that automorphism is identity when `appTop` is injective.
7. **Field-valued point consumer.** For the unchanged original complete
   contact source, every actual field-valued point has injective `appTop`.
   The proof uses the proved original structural Q constants and injectivity
   of a field ring homomorphism, not an assumed Q-rational point.
8. **Exact finite-extension point.** `actual_point_faithful` and
   `actual_rigidified_aut_eq_one` use the exact `RationalContactPoint318.point`
   with the original units and parameter. Its original source, actual field,
   module pullback, trivialization and automorphism are retained verbatim.
9. **Boundary.** The final rigidity theorem concerns original source lines
   rigidified at that actual point. It does not cover arbitrary new lines on
   arbitrary base-changed families. Universal `p_* O = O`, effective descent,
   degree zero, representability, a Jacobian, norm, polarization and isogeny
   are not asserted. No rational point of the original source is assumed.
