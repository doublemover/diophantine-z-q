# Genuine fppf line descent over affine bases

This pending packet discharges the previously explicit refinement hypothesis on affine base schemes. It constructs a finite affine refinement of the actual flat quasi-compact covering family, takes its original coproduct, and proves the map back to the original cover and its exact factorization. The prior original line/descent category equivalence then applies without assuming the original source affine.

For fppf arrows, flatness and local finite presentation imply openness, which gives the required quasi-compact-cover condition. The original arrow need not itself be quasi-compact. The final module applies this to the actual coproduct arrow of every genuine small fppf covering family, including infinite families and non-affine components. The forward map on each original component is retained through its exact coproduct pullback path.

The187 producer sources are unchanged copies of refined-cover-categorical-descent-r3, including its generic categorical proof repair for the earlier hosted kernel timeout. Four sources are new. Static checks and bounded source review are not hosted proof acceptance. No local Lean compilation was run.

Descent over a general non-affine base still needs local assembly of these affine-base constructions; represented Picard/Jacobian and the arithmetic theorem are not asserted. The final family theorem uses descent data on the full original coproduct cover; a separate equivalence with an indexed family presentation is not claimed.
