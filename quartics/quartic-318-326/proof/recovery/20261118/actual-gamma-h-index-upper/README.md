# Character-kernel congruence subgroup index

For each prime power p^e exactly dividing N, take the first column (x,y) of an actual SL₂(Z) matrix. In the local residue ring one coordinate is a unit. If x is a unit, record y/x; otherwise record the nonunit x/y. The two possible charts have at most p^e+p^(e−1) labels together. Equal labels at all primes force the cross-determinant to vanish modulo N by CRT; equivalently the matrices represent the same SL₂(Z)/Γ₀(N) coset. Thus no simultaneous integral lifting of all labels is needed. Combining with the surjective actual lower-right residue map Γ₀(N)→(Z/N)× gives [SL₂(Z):Γ_H]≤N[(Z/N)×:H]∏(1+1/p), also for N=1.

Independently reviewed mathematical and static Lean sources; not compiled. This is an index bound for the genuine group, not yet a bound for the algebraic degree by itself.
