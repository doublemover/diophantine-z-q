## Infinite tail for this single-prime sieve

For Z<ℓ≤X^(1/4) each excluded condition is one reduced class modulo a Gaussian ideal of norm ℓ², with Φ ≫ ℓ². The number of Gaussian prime elements of norm ≤X in one class is ≪ X/(ℓ² log X), uniformly here by Hinz–Lodemann's number-field Brun–Titchmarsh theorem (Paul Pollack, *A Titchmarsh divisor problem for elliptic curves*, Lemma 2.5, https://www.pollack-math.net/titchmarsh-final.pdf). At most eight classes per ℓ gives total ≪X/(Z log X). This absolute upper bound need not be uniform in the density of the fixed base. For larger ℓ the pertinent lattice is a translate of an ideal of norm ℓ², a rotated square lattice with mesh ℓ; hence O((√X/ℓ+1)²) points in the norm ball. An excluded square divisor ℓ²|N(π±1) implies ℓ≤√X+1; an inert divisor has the same consequence. For a shared split divisor, ℓ divides Reπ and (Imπ)²+1, so again ℓ≤√X since Reπ≠0 for a degree-one Gaussian prime over an odd prime. Summing over all integers X^(1/4)<ℓ≤√X+1 gives O(X^(3/4)+√X log X)=o(X/log X). Take Z fixed and then X large; since the finite-sieve density has a positive lower bound independent of Z, choose Z sufficiently large that the residual single-prime union bound is smaller. The all-ℓ set retains positive relative lower density. This is not a growing-cutoff Chebotarev estimate.
