# Degree bound for the concrete coarse marking resolvent
For the actual generic marked curve, form the polynomial product of T−x([u]P) over u in H. Coefficients generate an actual arithmetic field, bounded in degree by [SL₂(Z):Γ_H] without any primitive-equation or irreducibility assumption. Sign and other repetitions are retained, not divided out. For the ordinary x-coordinate diamond realization (using the separately stated primitive-root condition), its invariant functions embed in this concrete field by checking their values on the x-generator. No unconditional equality with a separately named modular-curve function field is claimed in Lean. Independent static/paper source review.
