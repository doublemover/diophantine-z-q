At the remaining fixed primes other than 7 compute the local squareclass of θ from D mod p, which is nonzero; for the four new primes use D mod p² since their depths are exactly one.

At each tested p we compute the exact local Kummer image. The infinity point and the three root/derivative formulas give actual local classes. Additional affine abscissas around the three roots are kept exactly when the rational cubic value is a nonzero square in Qp, using the usual valuation and residue test. Reaching four distinct pairs at odd p or eight at 2 proves exhaustivity: the local index of doubling is four, respectively eight, with full split 2-torsion (by the additive Haar scaling/finitely indexed formal group).     Sel₂(Jₖ/Q) ∩ Gₖ² = { (1,1),(1,β) }.

This is an exact subspace statement, not a bound extrapolated from a sample of global Selmer elements. It includes every discriminant prime of the constant baseline curve, not just the prime support of B.

Equivalently on Sel₂ take all valuation parity pairs at primes q|θ, q∉Sₖ. The kernel equals the displayed subspace. At each such q the nonidentity rational root torsion points have the three nonzero parity pairs (1,0),(0,1),(1,1), in an order independent of q since r₁,r₂,r₁−r₂ all have odd valuation. Therefore a Selmer element whose parity signature is constant across all such q can be adjusted by rational 2-torsion to land in the two-element kernel. Any independent Selmer class modulo these torsion images and δ must separate two true complement primes. A possible nonzero alternating Cassels row against δ on this curve must therefore use a class with nonconstant signatures, since δ pairs trivially with itself and with rational torsion. This narrows the arithmetic required for a global test; it does not promise there is a nonzero alternating row.
