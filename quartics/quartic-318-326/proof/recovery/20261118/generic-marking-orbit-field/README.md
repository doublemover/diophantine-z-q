# Galois field of moduli of one generic diamond orbit
Fix a finite Galois extension L of the arithmetic open-j function field and any point P of exact order N on its actual generic elliptic curve over L. The automorphisms σ with σP=[u]P for some u in a specified diamond subgroup H form a genuine, not necessarily normal, subgroup. Its fixed field has degree at most [SL₂(Z):Γ_H]; the proof embeds its cosets in actual primitive-marking classes. No finite étale splitting or geometric surjection is assumed. Existence/coverage by algebraic points and the identification of this field with the modular curve's function field are not conclusions. Independent paper/static Lean-source check, not a native result.
