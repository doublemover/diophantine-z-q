# One-way coarse residue-field embedding
For the true generic arithmetic curve and an actual algebraic marking P, evaluate rational coordinate functions with coefficients in Q(j). Galois equivariance follows from polynomial evaluation itself. If their values on H·P are constant, the field they generate lies in the genuine orbit-stabilizer field, which bounds the degree of any coarse field admitting an embedding in these values. The source's total conventions for division by zero and coordinates (0,0) at the identity are not rational evaluation there; for the rational interpretation P must be affine and the denominator nonzero, or use another chart. This packet does not identify a particular coarse function field with the orbit field. Independent source review, no kernel execution.
