# Tame involutions over coefficient domains

Six modules, 33 public theorems and 123 exhaustively audited declarations pass a fresh strict kernel replay. Only propext, Classical.choice and Quot.sound occur.

Let R be an actual commutative domain in which 2 is a unit. For an actual formal series F with zero constant coefficient, F composed with itself equal to X, and F not equal to X, the theorem constructs the explicit normalized parameter H=(X-F)/2. It proves H composed with F equals minus H and that each invariant series is uniquely g(H squared). No coefficient-field, characteristic-zero or tangent-faithfulness premise is assumed. Tangent-one triviality is proved by the plus-average and the actual compositional inverse of its unit-linear parameter.

The even/odd decomposition also constructs the actual ring isomorphism from QuadraticAlgebra R[[S]] S 0 to R[[T]]. A distinct actual series-ring copy with base S mapped to T squared has a constructed power basis (1,T), is finite free, and has rank two. A normalized-parameter ring isomorphism sends the generator to H and the base f to f(H squared). `RingNormalizedModel318.actual_model` combines this concrete model with the actual nontrivial involution.

These results apply to zero-constant formal charts over mixed-characteristic coefficient DVRs whenever 2 is a unit. The actual arithmetic different ideal for coefficient fields was proved in the separate quadratic-formal-extension packet. This packet does not claim that a general coefficient-domain power-series ring is a DVR or import that field-only different theorem into a two-dimensional local ring.
