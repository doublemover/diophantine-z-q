# Genuine open frames imply bundled local freeness

1. Required input is an actual Scheme module sheaf M, a covering indexed family V of actual open subschemes, and for each member an actual isomorphism from the free sheaf on the fixed index type I to M.restrict V.ι. Dimensions or bases of just one section module do not satisfy this input.
2. The construction retains M and each original restriction. overFrame uses Scheme.Modules.overEquiv to transfer an actual frame to the equivalent site-over-open model M.over V. It does not replace M by an unrelated module.
3. Coverage is the exact inequality top ≤ supremum V, converted through the pinned Opens.coversTop_iff. The index set and every member are retained, without silently shrinking to a smaller collection.
4. mapFreeIso uses the actual equivalence's original unit-sheaf isomorphism. The actual supplied frame and overFunctorEquiv are then composed and pulled back through the fully faithful functor. This produces genuine inverse maps in the original sheaf category.
5. Local generating sections are the images of the standard generators of the free sheaf under that exact frame. Their generator index remains I. The auxiliary frame_generators_iso reduces their canonical generator morphism to the actual given isomorphism, rather than guessing its bijectivity from a rank.
6. data_free proves the pinned LocalGeneratorsData.IsLocallyFreeData predicate. locallyFree then invokes its actual bundled SheafOfModules.IsLocallyFree theorem. This is not a new weaker predicate with a similar name.
7. The intended consumers are the actual fifth pushforward rank-eight sheaf frames and separately authored rank-one norm-clutched line frames. This helper does not assert that either consumer has supplied frames; each application must construct and identify them separately. There is no dependence on those consumers, so no cycle.
8. One module and all exported required endpoints pass strict kernel and recursive axiom audit, with only propext, Classical.choice and Quot.sound. The unchanged pinned official Mathlib LocallyFree module was missing from the local object cache, so its sole first-time dependency compile was performed in an isolated complete overlay. No official source/cache edit or whole-chain replay occurred. Distinct review remains separate.
9. No global free basis, global line triviality, determinant norm, Picard/Jacobian/PEL construction or full 318/326 completion follows from this generic criterion alone. This is an author application record, not independent acceptance.
