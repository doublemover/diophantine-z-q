# Actual GL2 torsor comparison for the literal frame cover

For nonzero N, this packet constructs an actual Scheme isomorphism

coproduct over g in GL2(F3) of Frame N  ->  Frame N x_(Base N) Frame N.

Its g-th component is exactly x -> (x, x.g), using the already checked actual GL2 action. Both projections, the inverse on every graph and the over-Frame structural map are identified. The acted-on Scheme is the original finite-etale surjective rank48 independent-pair cover, not a new abstract 48-element model.

The proof first establishes a bijection of actual geometric Scheme maps using the proved unique change between genuine bases. It then uses the separately checked étale-section theorem: the actual graph sections are open immersions with disjoint covering ranges, so their coproduct map is an isomorphism. This retains the full Scheme structures, including nilpotents. It is not an inference from pointwise bijectivity alone.

On a disconnected test, the comparison permits a locally constant GL2 change, rather than falsely requiring the same matrix on every component. No Weil pairing, symplectic level, PEL/modular-curve identification, Jacobian, polarization or final arithmetic conclusion is asserted.
