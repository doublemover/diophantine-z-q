## Reproduce

The snapshot pins Lean 4.35.0 and Mathlib commit 56a005855ea17e0b0958f73ec801ae140b0a1679. With Lean installed:

```sh
cd quartics/quartic-318-326/proof/progress
python3 verify_manifest.py
lake exe cache get
bash replay.sh
```

`replay.sh` kernel-checks every source in dependency order, then recursively audits all declarations, allowing only `propext`, `Classical.choice` and `Quot.sound`. It uses neither `sorry` nor native evaluation. The full finite enumeration is deliberately expensive. `bash replay.sh --audit-only` audits already built artifacts and does not claim a fresh source rebuild.

For this checkpoint, the 62 new modules were freshly rebuilt inside this snapshot with kernel checking. Earlier producer packets were separately checked. The full 767-module snapshot was hash/import-checked and recursively audited using those artifacts. The exact combined result and repository-check results are recorded in `checkpoint-verification.json`; it distinguishes that combined audit from a fresh rebuild of every snapshot module. Compiler binaries and the pinned Mathlib cache are trusted inputs.
