# Additional routes checked

The certified result of this search is the eight-coordinate primary reciprocal change in REPORT.md. The routes below are not additional savings.

1. Removing each alternate z_i by substituting -x_i/y_i initially appears to save a field variable. The actual compiled row has ell_0*LP_i=z_i*G_i because standalone ell_i was already eliminated. Clearing y_i yields y_i*ell_0*LP_i=-x_i*G_i, which is cubic. Restoring a product variable cancels the apparent saving.

2. After the primary reciprocal change, eliminating the H chart ordinate factor j_H by j_H=h_H*s would replace the chart relation by s^2=x_H-D*f_H, using x_H*f_H=1. Ordinary ordinate consumers h_H*j_H would become x_H*s without a new variable. However, the frozen 453 source already contains the improved V0 reciprocal chart. Its logarithm rows consume j_H*G0 and j_H*ell_0 individually. Substitution produces cubic terms. Rescaling its reciprocal coordinate g to g/h_H repairs these logarithm rows but changes f(V0)=g^2 into f(V0)=x_H*(g/h_H)^2, which is cubic. This route has no verified net saving.

3. The scalar ratio h_H*rho+j_H*z_S=0 can be replaced after the primary change by rho+s*z_S=0. Cancelling h_H is legitimate by the retained chart domain proof. This does not by itself remove a coordinate: substituting for rho in downstream quadratic consumers can raise the degree. It is left unchanged in candidate445.

4. Lowering the high Lucas order from 40 to 36, which would allow a degree-eight Taylor logarithm, is incompatible with the retained height exponent. The current argument compares B^2 with |F|^(19/k), and |F| can grow like B^4, so it needs k>38. This is an obstruction to that specific proof, not a lower bound on all possible constructions.

5. Both H and H-P cannot be made simultaneously deep in the same formal group by choosing the common multiplier. The completeness construction uses incompatible congruences h=0 and h=1 at separated prime supports. Thus a proposed common shallower approximation must still handle the alternate branch at depth one. The rational G9 proposal does this; a degree-two replacement for every alternate logarithm does not meet the retained order-40 tests.

6. Restricting selected split primes to p=7 modulo 8 would make -D a nonsquare in the residue field. A square-abscissa chart point then cannot reduce to T0=(0,0), and positive valuation of its z parameter would imply formality. This does not yet justify removing the four primary f(U_i) tests. When h is a p-unit, formality of H=[h]P does not imply formality of U_i=[u_i]P: multiplication by h can annihilate a nontrivial prime-to-p reduction component of P. Consequently z(U_i)/z(H) is not yet known to have the valuation of u_i/h, which is the missing premise in the integrality-transfer proof. The alternative case with h-1 a unit can use the formal alternate ratio, but both cases are required. No deletion is claimed.
